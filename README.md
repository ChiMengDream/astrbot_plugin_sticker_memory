# 表情包记忆（astrbot_plugin_sticker_memory）

把 QQ 账号里的「收藏表情」变成 Bot 自己的能力，而不是靠系统代发。

## 解决什么问题

大多数表情插件是"系统按情绪自动配一张"，Bot 自己不知道有表情库、也不知道发的是什么。这个插件反过来：**让她知道自己的库、自己挑、自己发，并且记得每张什么意思。**

## 功能

- **同步**：从 OneBot 网关拉取 QQ 收藏表情（emoji_id / 图片地址 / 官方描述）
- **自我认知**：每次请求注入一小段提示——你有 N 张收藏表情，可以用 `sticker_send` 发，约 40% 的回复里带一张
- **三个工具**
  - `sticker_list` 看库（返回 id、描述、备注、标签、用过几次）
  - `sticker_send` 发一张（按 id 或备注关键词）
  - `sticker_note` 给表情写备注（永久保存，越用越懂哪张适合什么场合）
- **自动收藏**：群里别人发的图，可按概率收进自己的表情库（`add_custom_face`），带开关、每日上限、群白名单
- **视觉打标**：让视觉模型看图，输出「画面｜场合｜标签」，自动写进备注和标签
- **WebUI 面板**：插件页里的「表情包库」，可预览、改描述、改标签、单张打标、删除、同步

## 安装

```bash
# 放进 data/plugins/
git clone https://github.com/<你的用户名>/astrbot_plugin_sticker_memory
```

重启 AstrBot（或在后台插件页重载）。

## 使用

| 操作 | 说明 |
|---|---|
| `/表情` | 看库统计 + 前 10 张 |
| `/表情 同步` | 从 QQ 拉一次收藏表情 |
| `/表情 打标 10` | 让视觉模型给 10 张没描述的打标 |
| `/表情 标签 <id或关键词> <标签1,标签2>` | 手动分类 |
| `/表情 删除 <id或关键词>` | 只删插件记录（QQ 收藏不动） |
| `/表情 自动收藏 开/关` | 开关自动收藏 |

后台「插件 → 表情包记忆 → 表情包库」有图形界面。

## 配置要点

| 配置 | 默认 | 说明 |
|---|---|---|
| `send_probability` | 0.4 | 她想发时，这个概率才真的发出去 |
| `send_cooldown_seconds` | 20 | 同一会话两次发表情的间隔 |
| `auto_collect_enable` | 关 | 自动收藏别人发的图 |
| `auto_collect_probability` | 0.15 | 每张图被收藏的概率 |
| `auto_tag_enable` | 开 | 新收藏的表情自动打标 |
| `tag_provider_id` | 空 | 打标用的视觉模型，留空用默认 |

## 依赖

- AstrBot >= 4.20
- 一个支持图片输入的模型（打标用，DeepSeek Flash / MiMo 都可以）
- aiocqhttp 协议端（NapCat / SnowLuma 等）

## 说明

- 表情以 **base64 图片段** 发送（收藏表情没有稳定的 mface 发送接口，图片段最通用）
- `add_custom_face` 会**真的写进 QQ 收藏**，QQ 收藏有上限，别把概率调太高
- 删除只影响插件本地记录；想彻底删除要去 QQ 客户端删收藏
